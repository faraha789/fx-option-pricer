
# FX Option Pricer

## Overview
A Python-based pricing application for European/American/japanese/suisse
foreign exchange (FX) options.

## Pricing Models
- Garman-Kohlhagen Model
- Monte Carlo Simulation
- Binomial Tree Model

## Features
- European Call and Put option pricing
- Interactive Streamlit interface
- FX market data integration
- Option payoff visualization

## Technologies
- Python
- NumPy
- Pandas
- SciPy
- Plotly
- Streamlit

## Installation

Clone the repository:

    git clone YOUR_REPOSITORY_URL

Install dependencies:

    pip install -r requirements.txt

Run the application:

    python -m streamlit run Pricer12.py
